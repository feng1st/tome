# monster Specification Delta

## ADDED Requirements

### Requirement: 怪物随机移动

怪物 SHALL 随世界时钟累积行动点，每满 100 点到达一次行动边界：先完成当前承诺（逻辑位翻转为承诺格），再决策下一行动——25% 随机选择一个方向（8 向均匀），目标格可通行则承诺走入该格，不可通行则本次原地不动；75% 原地不动。行动点消耗与是否移动无关。移动承诺 MUST 通过预判：世界剩余可行动量不足以走完该格时不发起。世界冻结时怪物 MUST NOT 决策。随机源 SHALL 可注入种子：同一种子下行动序列确定，可复现。

#### Scenario: 标准速度老鼠同步行动

- **WHEN** 主角连续移动，巨白鼠（速度 110）持续累积行动点
- **THEN** 主角每完成一步，老鼠恰好跨越一次行动边界

#### Scenario: 随机序列确定性

- **WHEN** 测试注入固定种子，主角走固定步数
- **THEN** 老鼠的行动序列（移动/原地、方向）确定可复现

#### Scenario: 撞墙原地不动

- **WHEN** 老鼠随机选中的方向目标格不可通行
- **THEN** 该次行动原地不动，行动点照常扣除

#### Scenario: 预判不发起

- **WHEN** 老鼠到达行动边界，而世界剩余可行动量不足以走完它的一格
- **THEN** 老鼠不发起位移，原地等待，余数留存

#### Scenario: 冻结不决策

- **WHEN** 世界冻结（主角无行动在进行）且老鼠行动点满 100
- **THEN** 老鼠不跨越边界、不决策、不位移

#### Scenario: 不停在半格

- **WHEN** 主角走完路径停下
- **THEN** 每只怪物的逻辑位与呈现位置都在整格上

## MODIFIED Requirements

### Requirement: 怪物词表注册表

怪物的种类 SHALL 由 core 的数据文件定义：词表文件以词条列表声明全部怪物 id，每个条目 SHALL 声明该怪物的 race id 与 speed（速率表原值），可声明 class id 与 unique id（unique id 即个体的名字，聚合进 unique 注册表）。加载时按条目出现顺序为每个 id 分配运行时句柄。句柄只是进程内一次加载中的临时标识，MUST NOT 假定其跨加载稳定；存档等跨加载场景 MUST 经"句柄 ↔ id"映射翻译。代码 MUST NOT 包含怪物枚举，也不以句柄或 id 判断怪物身份。新增怪物 MUST 只需在词表文件、形象绑定文件与形象表中各新增一个条目，不改动任何代码。

#### Scenario: 按名换取句柄

- **WHEN** 词表文件声明怪物 id 词条列表并加载
- **THEN** 每个 id 可换取一个句柄；同一 id 在同一次加载内换取的句柄相等，不同 id 的句柄不同

#### Scenario: 新增怪物不改代码

- **WHEN** 在词表文件、形象绑定文件与形象表中为一个新怪物各新增一个条目，并在地图文件声明其出生
- **THEN** 不改动任何代码即可加载该怪物并在游戏中呈现

#### Scenario: race 引用未知拒绝启动

- **WHEN** 怪物条目引用身份词表之外的 race id
- **THEN** 启动失败，错误信息指明出错文件与该 race id

#### Scenario: class 引用未知拒绝启动

- **WHEN** 怪物条目引用身份词表之外的 class id
- **THEN** 启动失败，错误信息指明出错文件与该 class id

#### Scenario: speed 缺失或非法拒绝启动

- **WHEN** 怪物条目缺失 speed 字段或 speed 超出速率表范围
- **THEN** 启动失败，错误信息指明出错文件与该怪物 id

### Requirement: 怪物出生

进入游戏状态时 SHALL 按当前地图的出生表为每个出生条目生成一个怪物实体：实体携带怪物句柄、其怪物条目所声明 race 的句柄、整格逻辑位与浮点呈现位（初值均为出生格）、由条目 speed 解析的速率组件、行动点组件；条目声明了 class 或 unique id 时，实体 SHALL 一并携带对应句柄。出生条目的怪物 id 未在词表声明时 SHALL 导致启动失败，错误信息指明该 id。

#### Scenario: 按地图声明出生

- **WHEN** 当前地图声明了若干怪物出生条目并进入游戏状态
- **THEN** 每个出生条目生成一个位于对应格子、携带对应怪物句柄、race 句柄、速率组件与行动点组件的实体；条目的 class 与 unique id 声明随实体一并挂载

#### Scenario: 未知怪物拒绝启动

- **WHEN** 当前地图的出生条目引用词表之外的怪物 id
- **THEN** 启动失败，错误信息指明该怪物 id

### Requirement: 巨白鼠数据

怪物词表 SHALL 声明条目 `( monster: "giant_white_rat", race: "giant_white_rat", speed: 110 )`；其形象绑定与形象数据由 creature-identity 与 figure 能力承接。测试房间 SHALL 声明两只巨白鼠出生，格子分别为 (28,10) 与 (24,13)。

#### Scenario: 测试房间呈现两只老鼠

- **WHEN** 启动游戏进入测试房间
- **THEN** 格子 (28,10) 与 (24,13) 各呈现一只播放 idle 动画的老鼠，且二者起始帧错开
