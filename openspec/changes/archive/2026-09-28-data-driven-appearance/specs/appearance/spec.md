# appearance delta: data-driven-appearance

## Purpose

生物外观的声明与解析：外观词表由 core 的数据文件声明并分配运行时句柄，每个外观的画法（贴图、图集网格、动画帧表）由 display 的数据文件定义；加载期校验保证词表与画法一一闭合，运行期按句柄解析画法。

## ADDED Requirements

### Requirement: 外观词表注册表

外观的种类 SHALL 由数据文件定义：core 的外观词表文件以字符串列表声明全部外观 id，加载时按条目出现顺序为每个 id 分配运行时句柄。句柄只是进程内一次加载中的临时标识，MUST NOT 假定其跨加载稳定；存档等跨加载场景 MUST 经"句柄 ↔ id"映射翻译。代码 MUST NOT 包含外观枚举，也不以句柄或 id 判断外观身份。新增外观 MUST 只需在词表文件与画法文件中各新增一个条目，不改动任何代码。

#### Scenario: 按名换取句柄

- **WHEN** 词表文件声明外观 id 列表并加载
- **THEN** 每个 id 可换取一个句柄；同一 id 在同一次加载内换取的句柄相等，不同 id 的句柄不同

#### Scenario: 新增外观不改代码

- **WHEN** 在词表文件与画法文件中为一个新外观各新增一个条目
- **THEN** 不改动任何代码即可加载该外观并供生物穿戴

### Requirement: 外观画法数据文件

每个外观的画法 SHALL 由 display 数据文件的一个条目定义：贴图路径、帧像素尺寸、图集行列数，以及动画帧表——帧表以动画词汇名给出帧序列与帧率。每个外观 MUST 定义 Idle 帧表；生物播放其外观未定义的动画时 SHALL 回退到 Idle 帧表。

#### Scenario: 从文件解析画法

- **WHEN** 加载画法文件
- **THEN** 每个条目解析为：贴图句柄、按帧尺寸与行列数构建的图集布局、按动画名索引的帧表

#### Scenario: 未定义动画回退 Idle

- **WHEN** 生物播放其外观未定义的动画
- **THEN** 实际播放该外观的 Idle 帧表

### Requirement: 外观数据校验

词表文件与画法文件 MUST 在加载时校验。词表中同一 id 重复出现、画法条目引用词表外的 id、同一 id 出现多条画法条目、词表中的外观缺少画法条目、帧序列为空、帧率非正、帧号越出图集网格、条目缺少 Idle 帧表，SHALL 导致启动失败，错误信息指明出错文件与出错位置。

#### Scenario: 词表外观缺少画法

- **WHEN** 词表声明的外观在画法文件中没有条目
- **THEN** 启动失败，错误信息指明出错文件与该外观 id

#### Scenario: 帧号越出网格

- **WHEN** 画法条目的帧序列引用图集网格之外的帧号
- **THEN** 启动失败，错误信息指明出错文件与该外观 id

### Requirement: 生物穿戴外观

生物 SHALL 以外观句柄声明自己穿戴的外观；显示侧按句柄解析画法，为实体挂载对应贴图、图集布局与动画状态。主角出生 SHALL 穿戴 warrior 外观。

#### Scenario: 按句柄挂载画法

- **WHEN** 一个声明了外观句柄的实体进入世界
- **THEN** 显示侧按句柄查到画法，为该实体挂载对应贴图、图集布局与初始动画状态

#### Scenario: 主角出生外观

- **WHEN** 游戏进入对局、主角出生
- **THEN** 主角穿戴 warrior 外观，画面上呈现 warrior 贴图的精灵

### Requirement: warrior 外观数据

warrior 外观的画法条目 SHALL 呈现既定表现：帧尺寸 12×15 像素，图集 21 列 8 行；Idle 帧序列为 0,0,0,1,0,0,1,1、帧率 8 fps；Run 帧序列为 2,3,4,5,6,7、帧率 20 fps。

#### Scenario: 数据条目与既定表现逐值一致

- **WHEN** 读取仓库中的词表文件与画法文件
- **THEN** warrior 在词表中声明，其画法条目的帧尺寸、行列数、Idle 与 Run 帧序列及帧率与上述数值逐项一致
