# Design: smooth-water-scroll

## 问题机理

像素完美画布把世界锁成 1:1 渲染后，任何慢于 1 纹素/帧的世界内运动都以整纹素为量子跳变。水面（-5 px/s 的统一 UV 平移）在 60fps 下每约 12 帧整片齐跳一格——所有像素同相位，最近邻采样下全场同时翻转。这就是 OPEN_ISSUES #2 的首次实锤。

排查顺路抓到第二个缺陷：12×15 主角精灵以整数格心为中心，奇数高度使四边形边缘落在半纹素上、骑在画布像素中心线——每行在两贴图行之间抽签，表现为"额头长一行、腿短一行"。

## 关键定理（本 change 的边界条件）

**2× 整数上屏下，硬像素块与亚纹素连续平移不可兼得**：窗口像素中心落在四分之一纹素处（半像素中心 × 0.5 投影），相邻窗口行的采样相位恒差 0.5 纹素；要连续平移就得把每个纹素块劈成两条不同混合的半行（横条纹），要硬块就只能按整窗口像素跳。本 change 的全部取舍都在这条定理的约束内。

## 否决路径（每条的死因）

| 路径 | 死因 |
|---|---|
| 画布内相位混合着色器（sharp-bilinear 族，OPEN_ISSUES #2 原登记方向） | 软化像素——用户要完美像素；且统一偏移下所有像素同相位，混合只是把"齐跳"换成"齐淡化" |
| 屏幕锁定水层（相对屏幕恒速滚动） | 实机观感如深渊——水纹不随世界，洞在上面滑 |
| 纯 UV 锁定（四边形钉死、锁定走 uniform） | 锁值要跨域传递且与滚动同帧（须引入 Present 相位）；用户裁决位置语义更直白 |
| 视口相机裁剪（bevy_pixcam 的 PixelViewport 路线） | 动态画布使其失去存在理由：画布恒盖满窗口，水无处可漏 |
| 遮罩框（4 块遮挡 quad) | 同上，且是遮挡而非裁剪 |

## 最终架构的决策

### D1: 屏幕空间动画地形层（位置锁定 + UV 流动）

水从世界 pass 撤出。画布相机清屏透明 → 地形格成为 alpha-0 洞；地图尺寸的地形层垫在画布精灵之下（z = -1），预乘 alpha 合成恰好从洞里透出（岸线半透明像素同理会合）。

- **世界锁定走位置**：跟随装置每帧把层置于 `world_anchor − target`（地图中心为锚）——与任何固定世界点同一定律。锁定的写者是 follow_target（camera 域；terrain_animation 若自锁会成依赖环）。
- **时间流动走 UV**:`animate` 系统按虚拟时间写 `uv_transform` 平移（repeat 比例尺烘进网格 UV）。与位置分属不同组件，无写入冲突、无相位排序需求。
- **零自定义着色器**：ColorMaterial + REPEAT 即可。
- 多类型共存（水+岩浆）需把地图尺寸四边形升级为格子并集网格——叠放的整图 quad 无法区分不同种类的洞。登记在 OPEN_ISSUES 与 `TerrainAnim` 的 Known limit。

### D2: 动态画布（视野随窗口）

画布纹理 = `⌈窗口逻辑尺寸/2⌉ 向上取偶 + 四边 2 纹素余量`，随 `WindowResized` 重建；画布精灵尺寸逐帧跟随 GPU 纹理（引擎行为），相机视野跟随渲染目标尺寸（引擎行为）。画布精灵恒盖满窗口，窗沿裁掉余量伸出。

- **偶数规则**：画布相机吸附整数世界像素，只有偶数画布让纹素中心落在世界纹素中心（半整数）；奇数尺寸整体偏移半纹素 = 逐纹素抽签。
- 余量圈保留：平移余量 ±0.5 纹素的覆盖不变。
- 视野语义反转：spec 从"视野恒定"改为"视野随窗口"。

### D3: 精灵纹素锚定

奇数尺寸的帧轴给半纹素锚点偏移（`texel_aligned_anchor`，归引擎 `Anchor` 组件承载），使四边形边缘对齐整数纹素网格。y 向下偏：脚底正好压格底线。规则通用（任意奇数帧尺寸），单测锁定。

## 参考与佐证

- **PD / Shattered**：世界锁定 UV 滚动层（SkinnedBlock）——我们克隆过的做法；它依赖直渲+高 zoom 蒙混，画布路线下失效。
- **bevy_pixcam**（社区事实标准，非官方）：`PixelViewport` 用相机视口做黑边——动态画布下我们不需要，但其事件驱动、物理像素换算、`PostUpdate` 排序纪律是视口路线的参照。
- **libretro sharp-bilinear**（Themaister，公有领域）：相位混合家族的正典——应用在本 change 被否决，记录备查。
- 引擎源码核实：精灵尺寸逐帧抽取自 GPU 纹理（bevy_sprite_render/render）；`ScalingMode::WindowSize` 跟随渲染目标而非窗口。

## 测试与验收

- 单测：尺寸规则（取偶）、尺寸重建、坐标映射、跟随三件套（吸附/平移/层锁定）、流动时间积分、锚定三例。
- 实机验收（用户）：拖窗伸缩视野、水锁地图流动、主角纹素锐利脚踩格底、虚空深色、暂停水停。
