# appearance Specification

## Purpose
生物形象的声明与外观的解析：形象词表由 core 的数据文件声明并分配运行时句柄，每个形象的外观（贴图、图集网格、动画帧表）由 display 的数据文件定义；加载期校验保证词表与外观一一闭合，运行期按句柄解析外观。

## Requirements

### Requirement: 形象词表注册表

形象的种类 SHALL 由数据文件定义：core 的形象词表文件以字符串列表声明全部形象 id，加载时按条目出现顺序为每个 id 分配运行时句柄。句柄只是进程内一次加载中的临时标识，MUST NOT 假定其跨加载稳定；存档等跨加载场景 MUST 经"句柄 ↔ id"映射翻译。代码 MUST NOT 包含形象枚举，也不以句柄或 id 判断形象身份。新增形象 MUST 只需在词表文件与外观文件中各新增一个条目，不改动任何代码。

#### Scenario: 按名换取句柄

- **WHEN** 词表文件声明形象 id 列表并加载
- **THEN** 每个 id 可换取一个句柄；同一 id 在同一次加载内换取的句柄相等，不同 id 的句柄不同

#### Scenario: 新增形象不改代码

- **WHEN** 在词表文件与外观文件中为一个新形象各新增一个条目
- **THEN** 不改动任何代码即可加载该形象并供生物呈现

### Requirement: 外观画法数据文件

每个形象的外观 SHALL 由 display 数据文件的一个条目定义：贴图路径、帧像素尺寸、图集行列数，以及动画帧表——帧表以动画词汇名给出帧序列与帧率。每个外观 MUST 定义 Idle 帧表；生物播放其外观未定义的动画时 SHALL 回退到 Idle 帧表。

#### Scenario: 从文件解析外观

- **WHEN** 加载外观文件
- **THEN** 每个条目解析为：贴图句柄、按帧尺寸与行列数构建的图集布局、按动画名索引的帧表

#### Scenario: 未定义动画回退 Idle

- **WHEN** 生物播放其外观未定义的动画
- **THEN** 实际播放该外观的 Idle 帧表

### Requirement: 形象与外观数据校验

词表文件与外观文件 MUST 在加载时校验。词表中同一 id 重复出现、外观条目引用词表外的形象 id、同一形象出现多条外观条目、词表中的形象缺少外观条目、帧序列为空、帧率非正、帧号越出图集网格、条目缺少 Idle 帧表，SHALL 导致启动失败，错误信息指明出错文件与出错位置。

#### Scenario: 词表形象缺少外观

- **WHEN** 词表声明的形象在外观文件中没有条目
- **THEN** 启动失败，错误信息指明出错文件与该形象 id

#### Scenario: 帧号越出网格

- **WHEN** 外观条目的帧序列引用图集网格之外的帧号
- **THEN** 启动失败，错误信息指明出错文件与该形象 id

### Requirement: 生物呈现形象

生物 SHALL 以形象句柄声明自己呈现的形象；显示侧按句柄解析外观，为实体挂载对应贴图、图集布局与动画状态。主角出生 SHALL 呈现 warrior 形象。

#### Scenario: 按句柄解析外观

- **WHEN** 一个声明了形象句柄的实体进入世界
- **THEN** 显示侧按句柄查到外观，为该实体挂载对应贴图、图集布局与初始动画状态

#### Scenario: 主角出生形象

- **WHEN** 游戏进入对局、主角出生
- **THEN** 主角的形象为 warrior，画面上显示 warrior 贴图的精灵

### Requirement: warrior 外观数据

warrior 形象的外观条目 SHALL 复现既定表现：帧尺寸 12×15 像素，图集 21 列 8 行；Idle 帧序列为 0,0,0,1,0,0,1,1、帧率 8 fps；Run 帧序列为 2,3,4,5,6,7、帧率 20 fps。

#### Scenario: 数据条目与既定表现逐值一致

- **WHEN** 读取仓库中的词表文件与外观文件
- **THEN** warrior 在词表中声明，其外观条目的帧尺寸、行列数、Idle 与 Run 帧序列及帧率与上述数值逐项一致
